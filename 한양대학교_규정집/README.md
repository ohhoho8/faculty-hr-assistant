# 한양대학교 규정집 원문

- 출처: [한양대학교 규정집](https://portal.hanyang.ac.kr/huas/iycy/ruleBook.do)
- 수집일: 2026-11-01 ~ 2026-11-02 (사이트에서 직접 내려받음)
- 이 저장소는 한양대학교의 공식 자료가 아니며, 최신 규정은 출처에서 확인해야 합니다.

## 파일

- `*.pdf`: 규정 화면을 인쇄한 파일
- `학교법인 한양학원 정관_20170629.pdf`: 2017.06.29 개정판 정관. **현행판이 아닙니다.**
- `별표1`(HWP), `별표2`(HWPX): 교원인사 규정의 첨부 별표 원본
- `별표1.xlsx`, `별표2.xlsx`: 별표를 엑셀로 옮긴 파일
- `text/`: 검색과 비교에 쓰는 텍스트 변환본. 규정 1개당 1파일이며 머리글과 줄바꿈을 정리했습니다.
  - `교원인사규정.txt`: 본문은 PDF에서 추출했고, PDF에서 빠진 2017.4.6 이후 부칙은 규정 화면에서 복사했습니다.
  - `연구년제.txt`: 규정 화면에서 복사한 전문입니다.
  - `학교법인한양학원정관_제44-47조.txt`: 최신 정관의 휴직 조문입니다. 확인된 최신 개정일은 2026.02.19이며, 정관 이미지를 보고 옮겨 적었습니다.
  - `별표1.txt`, `별표2.txt`: 엑셀 파일에서 변환했습니다. 별표 1의 `-`는 원본의 빈 칸이며, 엑셀에서 빠진 교수 1호봉의 직급은 보완했습니다.

## 알려진 한계

- 11개 PDF는 인쇄 과정에서 마지막 쪽이 빠졌습니다. 교원인사 규정은 26쪽 중 22쪽, 겸임교원은 25쪽 중 22쪽, 나머지는 1쪽이 없습니다.
- 교원인사 규정과 연구년제를 제외한 PDF의 누락분은 복원하지 않았습니다. 노사협의회 운영은 부칙 없이 제29조에서 끝나 뒤에 조문이 더 있는지 확인할 수 없습니다. 나머지는 본문 뒤 부칙까지 있고, 빠진 부분은 부칙으로 보입니다.
- 최신 정관은 제44~47조만 텍스트로 있습니다. 나머지 조문의 텍스트는 2017년판이므로 현행과 다를 수 있습니다.
- 교원업적평가 및 인사지침은 포함되어 있지 않습니다.
- PDF에서 변환한 텍스트는 글자는 정확하지만 줄이 바뀌던 자리의 띄어쓰기가 일부 빠졌습니다(연구년제 기준 15곳). 검색할 때는 공백을 무시하고 비교해야 합니다. `연구년제.txt`와 교원인사 규정의 복원 부칙, 정관 텍스트는 해당하지 않습니다.
