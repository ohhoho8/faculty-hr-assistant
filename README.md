# 교원인사 업무 지원 시스템

교원인사 담당 직원이 규정을 찾고, 요건을 확인하고, 절차 기한을 챙기는 일을 돕는 웹 애플리케이션입니다. 한양대학교 공개 규정을 근거로 만든 대학 행정직 지원용 포트폴리오입니다.

> 한양대학교의 공식 서비스가 아닙니다. 교원 정보는 모두 가상이며, 판정은 규정 문구 기준으로 실무 검증을 거치지 않았습니다.

## 해결하려는 문제

교원 인사 업무는 교원인사 규정, 연구년제 규정, 정관, 별표, 부칙에 걸쳐 있습니다. 예를 들어 조교수의 재임용 기간은 제16조만 봐서는 알 수 없고, 임용 시점에 따라 부칙의 적용 시기까지 확인해야 합니다. 이 시스템은 이렇게 흩어진 근거를 항목별로 연결해 보여줍니다.

## 주요 기능

| 화면 | 내용 |
|---|---|
| 대시보드 | 가까운 마감, 임용기간 만료, 승진·정년보장 자격 현황 |
| 요건 판정 | 승진, 재임용, 정년보장, 연구년, 휴직을 항목별로 판정하고 근거 조문을 연결 |
| 업무 일정 | 재임용 통지 기한, 연구년 신청 기한, 정년퇴직일 등을 교원별로 계산 |
| 규정 질의 | 조문을 검색해 근거 안에서만 답하고, 근거가 없으면 답하지 않음 |
| 규정 열람 | 18개 문서 708개 항목을 조문 단위로 열람 |

## 설계 원칙

- **판정은 코드로 계산합니다.** 같은 입력에는 항상 같은 결과가 나와야 하므로 AI가 합격 여부를 판단하지 않습니다. AI는 규정 질의의 답변 작성에만 씁니다.
- **규정에 없는 값은 만들지 않습니다.** 판정 결과는 `충족`, `미충족`, `확인 필요`로 나눕니다. 연구실적 기준처럼 규정에 수치가 없는 항목은 `확인 필요`로 표시합니다.
- **모든 판정 항목에 근거 조문이 있습니다.** 인용한 조문이 실제 규정에 있는지 테스트로 검증합니다.
- **AI가 지어낸 인용은 버립니다.** 답변의 인용은 검색 결과에 있는 조문으로 제한하고, 실제 조문을 인용하지 않은 답변은 표시하지 않습니다.
- **개인정보를 받지 않습니다.** 요건 판정은 브라우저 안에서만 계산하며 입력값을 저장하거나 전송하지 않습니다.

## 측정 결과

`npm test`로 재현할 수 있습니다. 검색 평가는 API 키 없이 동작합니다.

| 항목 | 조정용 세트 (37문항) | 별도 세트 (18문항) |
|---|---|---|
| 정답 조문이 상위 6개 안에 있음 | 37/37 | 17/18 |
| 정답 조문이 1순위 | 29/37 | 13/18 |
| 규정 밖 질문을 거절 | 7/9 | 5/6 |

별도 세트는 검색 조정을 마친 뒤 만들었고, 이 결과로 다시 조정하지 않았습니다. 평가 질문은 개발자가 직접 작성했으므로 실제 담당자의 질문과 다를 수 있습니다. 거절하지 못한 규정 밖 질문은 다음 단계에서 AI가 근거 부족으로 답하도록 했습니다.

AI 답변은 질문 8개를 표본으로 직접 읽어 확인했을 뿐, 정량 평가는 하지 않았습니다. 이 과정에서 육아휴직에도 임용기간 잔여기간 제한이 있다고 답하는 오류를 발견했습니다. 인용한 조문은 맞았지만 단서의 예외를 놓친 경우입니다. 조문의 단서를 확인하도록 지시를 고쳐 같은 질문에서는 바로잡혔으나, 같은 유형의 오류가 다시 나올 수 있습니다. 그래서 화면에서 원문 확인을 안내하고, 요건 판정에는 AI를 쓰지 않습니다.

판정과 일정 로직은 규정에서 직접 계산한 기댓값으로 작성한 테스트로 검증합니다.

## 알려진 한계

- **업적 기준이 없습니다.** 교원업적평가 및 인사지침과 학과내규를 확보하지 못해 승진·재임용·정년보장은 자격연수와 절차까지만 판정합니다.
- **정관은 일부만 최신입니다.** 제44~47조는 2026.02.19 개정 기준이고, 나머지는 2017년판이라 화면에 구버전으로 표시합니다.
- **PDF 변환 텍스트의 띄어쓰기가 일부 빠져 있습니다.** 글자는 정확합니다. 검색은 공백을 무시해 비교합니다.
- **규정에서 정할 수 없는 부분이 있습니다.** 제15호 휴직의 봉급, 임용기간과 근속기간의 관계, 연구년 근무기간의 산정 기준일은 `확인 필요` 또는 주석으로 밝혔습니다.
- **규정 자체의 불일치를 그대로 알립니다.** 교원인사 규정 제27조 제4항의 참조 항 번호, 연구년제 제5조 제2항이 인용하는 폐지 규정 등이 있습니다.
- **시연 기준일을 내부에 고정했습니다.** 가상 교원의 날짜는 실제 학사 일정에 맞춘 고정값이라, 언제 열어도 같은 현황이 보이도록 2026.11.02 기준으로 계산합니다. 대시보드와 업무 일정은 날짜 대신 남은 기간으로 표시합니다.
- **가상 일정이 포함됩니다.** 학교 공고로 정해지는 승진 접수와 심의 날짜는 알 수 없어 `가상 일정`으로 표시합니다.
- **사용량 제한은 서버 인스턴스별 메모리에 저장합니다.** 인스턴스가 늘면 한도도 그만큼 늘어납니다.
- **AI 답변은 느립니다.** 표본에서 질문당 8~22초 걸렸습니다. 30초가 지나면 찾아둔 조문을 대신 보여줍니다.

## 실행

```bash
npm install
```

```bash
npm run dev
```

http://localhost:3000 에서 열립니다. Gemini는 선택 기능으로, API 키가 없으면 규정 질의는 관련 조문만 보여줍니다. AI 답변을 쓰려면 `.env.example`을 참고해 `.env.local`에 `GEMINI_API_KEY`를 넣습니다.

| 명령 | 내용 |
|---|---|
| `npm test` | 판정, 일정, 질의응답, 검색 평가 |
| `npm run lint` | 코드 검사 |
| `npm run corpus` | 규정 텍스트에서 `data/corpus.json` 재생성 |

규정이 개정되면 `한양대학교_규정집/text/`의 파일을 교체하고 `npm run corpus`를 실행합니다. 규정집 사이트는 자동 수집을 금지하고 있으므로 실행 중에 접속하지 않습니다.

## 구조

```text
app/                     화면과 API
lib/rules/               승진, 재임용, 정년보장, 연구년, 휴직 판정
lib/schedule/            교원별 일정 계산
lib/search/              조문 검색
lib/ai/                  Gemini 연동과 인용 검증
data/corpus.json         조문 단위로 나눈 규정
eval/                    검색 평가 세트
한양대학교_규정집/         규정 원문과 텍스트 변환본
```

기술 구성은 Next.js, TypeScript, Tailwind CSS, Gemini API, Zod, Vitest입니다.
